# NOTICES·시간표 화면 디자인

2026-09-10. 공통 모달 개편 이후 각 화면의 용도에 맞춰 조정한 내용.

## NOTICES

- 기본 화면: 시간표처럼 흰색 카드 안에서 상단 제목/동작과 하단 검색/부서 필터를
  구분한다. 큰 제목 아이콘 배경을 제거하고 공지사항 메뉴의 로즈색을 아이콘·선택 상태에
  사용한다. 기간 전환은 앰버색 보조 동작으로 구분한다. 부서는 줄바꿈되는 선택 버튼이며
  미확인 공지는 점으로 표시한다.
- 제목·부서·작성자 검색을 추가했다. 기존 게시 중/전체 기간 판정과 정렬은 유지한다.
  검색 결과가 없으면 검색어 지우기를 제공한다.
- 목록에서 제목을 독립된 줄로 표시하고 부서, 기간, 작성자, 첨부 개수를 구분한다.
- 작성·수정 모달은 최대 768px, 헤더/푸터 고정, 본문만 스크롤한다.
  부서·게시 기간 → 제목 → 내용/링크 도구 → 첨부 순서로 구성한다.
- 링크 버튼은 좁은 화면에서 줄바꿈한다. 날짜 입력의 기본 최소 너비가 모바일 폼을
  밀어내지 않도록 grid와 입력 크기를 제한했다.
- 저장/첨부/캐시 갱신이 끝날 때까지 저장 상태를 유지하며 중복 제출과 닫기를 막는다.
  상세 화면은 선택 당시의 객체 대신 갱신된 목록에서 같은 ID를 우선 조회한다.

## 시간표

- 교사/학생 시간표의 카드와 주간 도구 영역을 정리했다.
  주간 이동·표/목록 전환·메모 버튼에 접근성 이름을 보완했다.
- `timetableDialogDesign.tsx`에 시간표 전용 헤더/푸터/아이콘/버튼 규칙을 모았다.
  수업 교체 탐색, 교체 신청, 대체 요청, 승인, 교체 문서, 교체 관리에 적용한다.
- 메모 작성, 메모 목록의 인라인 편집, 활동 추가는 본문과 하단 액션을 분리한다.
  학생 명단은 모바일 한 열, 넓은 화면 두 열로 배치하며 닫기 푸터를 추가했다.
- 교사/학생 시간표 업로드도 본문 스크롤과 헤더/푸터를 분리했다.
- 활동 추가에서 달력 열기 버튼이 form을 제출하지 않도록 `type="button"`을 지정했다.

## 컨테이너 효과

공지사항과 교사/학생 시간표의 헤더·본문 컨테이너는 스케줄의 `ImprovedCard`와 같은
그림자·300ms 전환·hover 시 2px 상승 효과를 사용한다. 헤더에는 반투명 흰 배경과
backdrop blur를 적용한다. `improved-card.css`의 `card-surface-effect`로 효과만 공유하여
시간표의 grid 배치와 기존 패딩을 유지한다. 공지 작성 버튼의 기본 파란색도 유지한다.

## 검증

```powershell
npm run build
# 개발 서버 실행, Playwright 모듈 경로 설정은 modal-system.md 참고
node scripts/modal-ui-test/run-feature-previews.mjs
node scripts/modal-ui-test/run.mjs
```

추가 회귀는 실제 화면 컴포넌트에 메모리 데이터 훅을 연결하여 실행한다. 백엔드 쓰기 없이
공지 검색/기간 전환/부서 선택/링크 삽입/저장 후 목록 반영, 모바일 가로 넘침,
시간표 메모 저장/목록 내 편집/활동 추가/달력 버튼의 제출 방지를 검증한다.
공지 링크 선택기는 테스트용 중첩 Dialog로 대체하며 실제 서비스의 조회 권한과 파일 업로드는
이 테스트의 범위가 아니다. 스크린샷은 OS 임시 디렉터리의 `spacekijun-notice*.png`,
`spacekijun-timetable-*.png`에 생성한다.

공용 레이어 동작과 규약은 [공통 모달 시스템](modal-system.md)을 참고한다.
DB 마이그레이션은 없다.
