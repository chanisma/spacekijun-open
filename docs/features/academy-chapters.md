# 제1장 · 나의 첫 별

기존 여섯 항목 튜토리얼 대신 연구시설에서 실제 탐구 하나를 설계하는 이야기로 시작한다. 프롤로그 완료·건너뛰기 후 제1장을 열며, 기존 학생도 이전 활동을 삭제하거나 완료로 간주하지 않고 새 챕터를 시작한다. 이야기를 닫고 자유롭게 둘러볼 수 있고 다음 입장이나 여정 메뉴에서 저장된 장면부터 이어간다. 과거 튜토리얼·도서관 의뢰·연속 의뢰 데이터는 보존한다. 도서관의 첫 의뢰 안내는 제2장으로 통합했다. 기존 연속 의뢰는 제2장 이후의 곁이야기로 유지한다. 자세한 내용은 `academy-library-chapter.md`를 참고한다.

## 이야기와 실제 행동

1. 광장에서 루온이 연구시설로 초대하고 리아가 동행을 결심한다.
2. 연구시설 입장 CG: 별빛 돔과 망원경에 놀란 리아, 곁에서 소개하는 루온.
3. 카시안과 첫 만남. 관심·활동을 별로 보는 망원경 설명.
4. 기존 지식 그래프를 망원경 화면에서 실제로 조작한다. 별을 선택해야 발견 대사로 넘어갈 수 있다. 키보드로 사용할 수 있는 별 선택도 제공한다.
5. 리아가 자신의 별에 기뻐하고 새로운 별을 찾고 싶다고 말한다. KG가 없는 학생에게는 빈 하늘에서 첫 질문을 시작하는 별도 대사를 보여 준다.
6. 카시안이 연구대의 지도·설계지·보라색 수첩을 설명한다. 연구대의 실제 종이를 눌러 설계를 시작한다.
7. 기존 탐구 기능으로 수업·활동 선택, 질문·교수 대화, 설계 생성, 학생 본인의 이유를 적은 확정 저장까지 진행한다.
8. 확정한 설계 제목을 표시하며 카시안의 인정 → 리아의 기대 → 루온의 축하 → 교수의 재방문 초대 순서로 마무리한다. 설계만 저장하고 축하 대사를 아직 읽지 않은 상태와 제1장 완료를 구분한다.

## 저장과 권한

`academy_chapters`는 학생별 `first_star` 챕터의 0~16 단계·revision·관측 분기·설계 ID/제목·시각을 저장한다. 직접 쓰기를 막고 `academy_chapter_read/write`의 실제 역할 확인을 거친다. 관리자 선택 학생 미리보기는 읽기 전용이다. 각 대사 저장은 한 단계씩만 이동하며 revision으로 중복 클릭/늦은 응답을 막는다. 이동·관측·연구대·설계 단계는 일반 다음 버튼으로 넘기지 않는다. 관측 입력은 플레이어의 UI 상호작용 기록이며 서버가 화면을 실제로 보았는지 증명하는 방식은 아니다.

최종 설계는 같은 학생의 `student_inquiry_designs`에서 `saved/observed`, 챕터 시작 이후 생성, 본인 이유 10자 이상인 행만 허용한다. 초안·교사 제안·다른 학생 설계·이전 탐구로 건너뛸 수 없다. 새 탐구 저장은 기존 `save_inquiry_design_with_ontology`를 그대로 사용해 KG와 같은 DB에 보관한다. 설계는 저장됐으나 챕터 기록이 실패하면 제1장의 ‘이미 확정한 탐구로 이야기 이어가기’에서 해당 설계를 다시 연결한다. 탐구를 중복 생성할 필요가 없다.

## 화면과 자산

게임 내부의 큰 인물 초상과 타이핑 대사를 사용하며 리아 초상은 남성보다 작다. 입장 CG는 `chapter-observatory-arrival.png`(1536×1024)이며 기존 리아·루온·연구시설 원화를 참조해 built-in imagegen으로 제작했다. CG는 기본 의상의 고정 삽화이고 일반 대화 초상은 현재 착용 의상을 반영한다. 모바일에서도 두 인물의 얼굴이 남도록 중앙 구도를 사용한다. 입장 장면을 읽은 책갈피는 다음 방문에 반복하지 않는다. 원본 자산을 덮어쓰지 않았다.

`20260913171543_academy_first_chapter.sql`은 기존 아카데미 스키마와 student_inquiry_designs 이후 적용한다. 실제 DB의 `supabase/tests/academy_chapter.sql`은 순서·재시도·확정 설계 검증·타 학생 격리·관리자 제한을 검증하고 롤백한다. 브라우저 fixture는 실제 React/Phaser/KG 화면을 사용하고 실사용 학생에 대한 AI 요청과 저장은 차단한다.

검증 결과(2026-09-13): DB 적용 및 역할 테스트 완료. 관련 자동 테스트 35개, 대상 ESLint, 프로덕션 빌드, 전체 아카데미 브라우저 회귀 검사 통과. 챕터 검사에는 첫 입장 CG의 데스크톱/모바일, 읽은 장면 재생 방지와 책갈피 복구, 별 선택 전 진행 제한, 실제 설계 저장 후 챕터 저장 실패의 복구, 빈 별자리 대사, 교수와 루온의 축하, 관리자 읽기 전용을 포함한다. 새 챕터 관련 Advisor 지적은 없다. 프런트엔드 호스팅 배포는 하지 않았으며 localhost:8080에서 확인할 수 있다.

전체 앱 타입 검사는 기존 다른 영역의 오류 230개로 실패한다. 이번 챕터 및 아카데미 변경 파일의 타입 오류는 없다.
# 제1장 완료 연출 (2026-09-13)

진행 상태가 16으로 저장된 뒤 전용 축하 화면을 표시한다. `chapter-first-star-complete.png`에서 첫 별을 찾고 기뻐하는 리아와 이를 축하하는 루온·카시안 교수가 함께 등장한다. 일러스트가 서서히 나타나고 별빛이 떠오른 뒤 ‘제1장, 나의 첫 별’ 완료 문구와 실제 확정한 설계 제목이 나타난다. 효과는 반복하지 않으며, 동작 줄이기 설정에서는 정적인 화면으로 즉시 표시한다. 모바일에서는 일러스트 전체가 보이도록 배치한다.

완료 화면의 버튼으로 교수 대화 또는 아카데미 탐험을 이어간다. 처음 챕터를 완료하면 50코인을 지급하고 완료 화면에 표시한다. 재감상은 기존 완료 상태를 재사용하므로 추가 보상을 발생시키지 않는다. 재접속 시 완료한 장을 자동 재생하지 않으며 여정 메뉴에서 다시 볼 수 있다. [보상 저장과 검증](academy-chapter-rewards.md).
# 챕터 이미지 전환 보완 (2026-09-14)

제1~5장 캐릭터·장면·완료 이미지는 공통 `ChapterImage`로 표시한다. 이미지 주소나 표시 스타일이 바뀌면 새 이미지 요소를 생성하고, `HTMLImageElement.decode()`가 완료될 때까지 숨긴다. 준비가 끝난 시점부터 기존 등장 애니메이션을 시작하며 동작 줄이기 설정을 유지한다. 따라서 새 장면의 전체 화면 스타일이 이전 캐릭터 그림에 적용되어 확대되는 현상을 방지한다.

전환 도중 떠난 이미지의 디코딩 결과는 무시한다. 불러오기에 실패한 이미지는 숨긴 상태로 두며 대사와 이동 버튼은 계속 사용할 수 있다. `scripts/academy-test/chapter-image-browser-checks.mjs`에서 데스크톱·모바일의 다운로드 지연, 디코딩 지연, 이전 이미지 제거, 이전 대사 이동 중 늦은 완료, 캐시된 이미지, 등장 효과와 동작 줄이기를 검증한다.
