# 별빛 기숙사 · 일정과 꾸미기

2026-09-13. `/academy/dorm`은 기존 게임 안에서 이동하는 다섯 번째 공간이다. `D:\kidon\src\pages\Index.tsx`의 좌측 월간 달력·중앙 캐릭터·우측 할 일·하단 메뉴 배치를 참고해 기숙사 원화 위에 구현했다. 보라색 반투명 패널, 금장 테두리, 달·별 장식 버튼으로 로판 분위기를 유지한다. 기숙사 입장 즉시 이 화면을 펼치며 기존 웹 서비스로 이동하지 않는다.

## 학생 화면

- 계획장: 월간 달력과 이전/다음 달, 오늘 복귀, 날짜 직접 선택. 선택한 날의 시간 있는 약속과 시간 미지정 약속, 중요도, 목표 연결, 메모, 수정·삭제·실천 표시를 지원한다. 목표를 만들거나 이루었다고 기록할 수 있다. 날짜 기준은 서울이며 시작·종료 시각은 같은 날 범위로 검증한다.
- 하단 ‘시간별 계획’에서 우측 시간표를 펼친다. 0~23시의 빈 시간 선택은 시작·종료를 채운 편집기로 이어지며 마지막 시간은 23:00~23:59다. 기존 약속이나 시간 미지정 약속도 선택하여 시간을 수정한다. 달력에 아직 읽지 않은 날짜의 완료 수나 계획 표시를 추정해서 그리지 않는다.
- 기숙사에는 리아만 등장한다. 중앙 상태판은 실제 선택 날짜의 실천 수·코인·진행 중 목표 수를 표시한다. 루온의 방 안 NPC와 대화 표식은 제거했다. 모바일은 kidon처럼 달력·기록·캐릭터를 세로로 배치하고 하단 메뉴는 게임 화면 안에 고정한다.
- 오늘 날짜의 계획을 처음 완료하면 5코인을 지급한다. 하루 한 번이며 완료 취소·재완료·계획 삭제로 반복 지급되지 않는다. 실천 여부는 학생의 자기 기록이다.
- 옷장: 리아와 루온의 의상을 독립적으로 적용·해제한다. 얼굴과 헤어스타일을 참고 원화로 고정하고 의상만 바꾼다. 캐릭터 선택이나 얼굴 생성 기능은 없다. 착용한 의상은 탐험 장면과 루온 대화 초상화에 이어진다. 프롤로그·동작 CG는 서사의 고정 의상을 사용한다.
- 공방 주문서: kidon 상점의 좌측 착용 미리보기·우측 상품 카탈로그 구조로 구성했다. 미리보기 → 코인 사용 확인 → 구매 → 적용. 루온은 ‘루온 의상’ 분류를 고를 때만 착용 미리보기에 표시된다. 초기 추가 상품은 리아 장미 산책복, 루온 청람 예복, 장미빛 침실, 별빛 침실 4종이다. 기본 의상과 기본 방으로 돌아갈 수 있다. 방 꾸미기는 가구를 개별 이동하는 편집기가 아니라 침구·장식이 함께 바뀌는 테마다.
- 기존 kidon 아이템은 삭제하거나 임의 변환하지 않는다. 보유한 예전 아이템은 ‘이전 소장품’에서 확인한다. 쿼카 전용 구상품은 아카데미 캐릭터에 장착하지 않는다.
- 관리자는 선택한 학생의 기숙사 기록과 꾸미기를 읽기 전용으로 미리 볼 수 있다. AI·코인·계획 쓰기 권한은 실제 학생에게만 있다. 선택한 학생 계정이 없으면 빈 기록이며 미리보기 중 데이터를 만들지 않는다.
- ‘방만 바라보기’로 달력·계획·상점·하단 메뉴를 숨기고 현재 꾸민 방과 리아만 감상할 수 있다. 우측 위의 메뉴 복귀 버튼 또는 Escape로 돌아간다.
- 공방에서 직접 프롬프트를 적는 맞춤 주문과 배송함을 지원한다. 관리자에게 접수 알림을 보내고, 관리자가 외부에서 제작한 PNG를 검수·등록해 배송하면 학생이 상자를 열어 개인 소장품으로 받는다. [공방 상세](academy-workshop.md).

## 권한과 일관성

클라이언트의 기존 코인 UPDATE·아이템 INSERT를 허용하지 않는다. 실제 학생 역할과 `auth.uid()`를 검사하는 `academy_private`의 내부 함수로 구매·장착·계획 쓰기를 실행한다. public RPC는 invoker 래퍼이며 내부 함수는 고정 search_path와 명시적인 EXECUTE 권한을 가진다. 요청에 user_id·가격을 넣어도 사용하지 않는다. 사용자 단위 트랜잭션 잠금으로 동시 구매와 장착을 직렬화한다. 잔액 차감과 지급은 하나의 트랜잭션이며 중복 구매는 추가 차감하지 않는다. 다른 사람 목표 연결·기록 변경을 거부한다.

일반 테이블 SELECT는 본인 RLS, 관리자 미리보기는 서버에서 실제 관리자 역할 및 학생 코드를 확인하는 읽기 RPC다. RPC 결과는 해당 학생의 전후 3일 계획·목표·소장품·코인과 상품 목록이다. 기존 일일 회고/피드백/대륙/설정은 이름을 바꾸어 보존하며 이번 계획장 화면에 전체 편집 기능을 이식하지는 않았다.

## 계획장 버튼 토글과 시간표에서 시간 고르기 (2026-09-14)

- **[＋ 계획 적기]·[＋ 나의 목표 적기]는 토글이다** — 입력란이 열린 채 한 번 더 누르면 접혀 목록으로 돌아간다(사용자 지시). 열린 동안 라벨이 [계획 목록 보기]·[목표 목록 보기]로 바뀌고 `aria-pressed` 로 상태를 드러낸다. 판정은 "그 탭의 입력란이 열려 있는가"(`task && tab==='day'`, `goal && tab==='goals'`)라 다른 탭의 폼이 열려 있어도 새로 쓰기가 막히지 않는다.
- **계획 입력란의 시간은 시간표에서 고를 수 있다** — 시작·마침 아래 [◷ 시간표에서 고르기]가 기존 시간별 계획 서랍을 **고르기 모드**(`pickForForm`)로 연다. 이 모드에서 빈 칸을 드래그하면 새 계획을 만드는 대신 **작성 중인 폼의 시작·마침을 채우고** 서랍이 닫힌다(제목·중요도·연결 목표는 그대로). 독 메뉴의 [시간별 계획]으로 열면 평소대로 드래그가 새 계획이 된다 — 같은 서랍이 두 뜻을 가지므로 안내문이 지금 어느 모드인지 말한다. 서랍에서 기존 계획을 눌러 편집으로 들어가면 고르기 모드는 해제된다.

기본 방 화면 왼쪽에 책(계획장 펼치기), 옷(옷장·방 꾸미기), 두루마리(공방 주문서 쓰기) 아이콘을 표시한다. 기존 lucide SVG를 금장 로판 버튼으로 꾸몄고, 별도 래스터 자산은 추가하지 않았다. 공방 아이콘은 맞춤 제작·배송함을 바로 연다. 상단 눈 아이콘은 물건 아이콘만 숨기거나 다시 표시하며, 배경 클릭으로 열림 상태를 변경하지 않는다. 세린 대화 버튼은 인물 발 아래에 유지한다.

리아의 높이는 방의 55%에서 64%, 세린은 53%에서 62%로 키웠다. 모바일에서는 이미지 너비 제한도 넓혀 키를 늘린 효과가 유지되도록 했으며, 아이콘을 작게 배치해 얼굴을 가리지 않도록 했다. 계획장 내부와 다른 장소의 인물 크기에는 이 규칙을 적용하지 않는다.


하단 메뉴 정리: 계획장에서는 계획장·나의 목표·시간별 계획만 제공한다. 옷장·방 꾸미기와 공방 화면에서는 옷장·공방만 제공한다. ‘방만 바라보기’는 하단에서 제거하고 상단 ‘← 기숙사 방으로’로 돌아간다. 방 기본 화면의 세 물건 아이콘으로 다른 기능에 진입한다.

광장 이동 시에는 방 패널을 먼저 닫지 않고 불투명한 전환 화면을 그 위에 표시한다. 이동 중 기존 원형 상호작용 버튼을 숨기고, 목적지의 Phaser 장면을 동기적으로 바꾼 뒤 두 애니메이션 프레임 후 전환 화면을 걷는다. 일반/동작 줄이기 설정 모두 같은 전환 순서를 따른다.

제3장 적용: 기숙사는 제2장 완료 후 열리며 세린의 자유 대화는 제3장 완료 후 열린다. 첫 목표와 연결된 시간 계획을 실제 저장하는 이야기, 목표 목록의 완료/취소·삭제, 계획별 선택 피드백을 추가했다. 기존 Kidon 테이블을 그대로 사용하고 목표를 지워도 계획/피드백은 보존한다. 상세: [기숙사 챕터와 계획장](academy-dorm-chapter.md).
