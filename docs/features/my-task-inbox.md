# 내 업무 / 내 이벤트

`/tasks`의 기본 탭(`tab=myWork`)은 담당자 개인의 실행 목록이다. 기존 이벤트 단위 통합 화면은 `tab=myEvents`(내 이벤트)로 이동했다. 탭 순서는 내 업무 → 내 이벤트 → 업무 흐름 → 타임라인 → 이벤트 검색이다. 이벤트 검색(`tab=events`, 기존 이벤트 관리)·업무 흐름·타임라인은 기존 기능을 유지한다.

## 내 업무

- `useMyTasksJsonb(true)`로 담당·관리 업무를 조회한다. 왼쪽 목록은 `assigned_tasks`만 사용하고, 계획표는 관리 이벤트의 업무도 포함한다.
- 기본 **할 일** 목록은 마감 지남 → 오늘 → 다가오는 업무 → 마감일 없음 순서다. **완료**, **전체** 필터와 업무명·이벤트명·설명 검색을 제공한다. 시작 대기와 취소는 전체에서 확인한다.
- 개인 상태는 기존 `getMyTaskStatus` 규칙을 사용한다. 업무 또는 이벤트가 종료되면 미제출 상태라도 할 일에서 제외한다. 반복 업무의 대표 마감은 본인이 완료하지 않은 첫 회차다.
- 일반 업무는 본인의 완료/취소 RPC를 재사용한다. 반복 업무는 회차별, 과제 단위 업무는 기존 단위 선택·완료 UI를 이용한다.
- 파일·양식 문서 제출은 기존 제출 다이얼로그와 작성 화면을 재사용한다. 내 업무에서는 본인 제출에 집중하며, 관리 기능은 내 이벤트에 남긴다.
- 업무 제목을 누르면 기존 상세 화면에서 설명·첨부 자료를 확인한다.

## 업무 계획표

넓은 화면에는 목록 오른쪽 패널, 좁은 화면에는 목록 위에 표시한다. 페이지 헤더의 **계획표 접기/열기**와 패널의 닫기 버튼을 제공하며 표시 설정을 로컬 저장한다. 목록 위 별도 제목·설명 영역 없이 필터·검색부터 시작한다.

월요일부터 일요일까지 **날짜 / 해야 할 업무**의 주간 스케줄표로 표시한다. 날짜별 행에서 그날의 업무와 제출/상세 버튼을 바로 보여준다. 이전 주·다음 주·오늘 이동을 제공한다.

계획표에는 본인 담당 업무와 본인이 관리하는 이벤트의 업무를 중복 없이 합친다. 관리 업무는 `관리`로 표시하고 **개인 완료가 아니라 업무 전체 완료**를 기준으로 남긴다. 담당자이자 관리자라면 본인이 완료했어도 다른 담당자가 미완료인 업무는 계획표에 남는다. 반복 회차도 관리 업무는 담당자 전원이 완료한 회차만 제외한다. 관리 업무의 **제출 현황**은 기존 관리자 제출 화면으로 연결한다. 마감일이 없는 업무는 계획표 하단 **마감일 미정**에 표시한다.

계획표는 등록된 마감 일정을 보여주며 마감일을 변경하지 않는다.

## 검증

- 프로덕션 빌드 및 신규 컴포넌트 ESLint 검사.
- 개인 완료와 전체 종료 우선순위, 이벤트 대기·완료·취소, 반복 회차 제외, 마감일 순서, 관리자 업무 혼입 방지 등 15개 로컬 검증.
- 계획표의 관리 업무 포함, 담당·관리 중복 제거, 개인 완료와 전체 완료 구분, 관리 회차 표시, 마감일 미정 등 13개 추가 검증.
- 샘플 데이터 브라우저 미리보기에서 주간 표 배치, 헤더의 계획표 접기/열기, 주 이동, 좁은 화면의 7개 요일 행 표시 확인. 실제 제출은 실행하지 않음.
- 전체 타입 검사는 저장소의 기존 오류가 남아 있으나 변경한 파일에는 오류 없음.
- 스키마·RPC·알림 데이터 변경 없음.
