# 문서 생성: 선택 영역 전체 반복과 병합 계층

2026-09-07. 문서 생성 화면이 사용하는 공용 task-workflow 문서 생성 엔진 수정.

## 반복 단위

사용자가 반복 행으로 선택한 **영역 전체**가 한 반복 단위다. 월 1개(4행 병합), 그 안의 주 2개(각 2행 병합), 각 주 안의 차시 2개로 된 영역을 두 번 반복하면 월 셀 2개, 주 셀 4개, 차시 행 8개가 된다. 월 셀을 전체 결과에 걸쳐 합치거나 마지막 주 병합을 잘라내지 않는다. 동일한 월 문자열을 입력해도 반복 단위의 셀 경계는 합치지 않는다.

수동 지정·재지정은 반복 원본인 locator.rows와 기존 예시 대체 구간인 replaceRows를 따로 기록한다. 한 행을 선택하면 그 행이 복제 원본이며, 같은 구조의 인접 예시 행들은 생성 내용으로 대체한다. 예를 들어 기존 예시 3행에서 원본 1행을 선택하고 5개를 작성하면 예시 3행이 새 5행으로 바뀐다. 기존 스펙에 replaceRows가 없으면 채움 시 동일한 규칙으로 해석한다.

대체 범위는 선택 행 앞뒤의 셀 구조와 상위 병합 소유 관계를 비교해 계산한다. 가장 가까운 상위 병합 경계, 셀 구조 변화, 헤더·합계에서 멈춘다. 반복 원본 밖이라고 무조건 보존하지 않으며, 계산된 예시 대체 구간 밖의 다른 구역은 보존한다. 이 자동 판별은 구조 기반이며 임의의 자연어 의미를 완전히 판별하는 기능은 아니다. 스펙의 replaceRows로 대체 범위를 명시할 수 있고, 검수 패널에 해당 범위를 표시한다. 자동 탐지된 연번 목록의 기존 단일 행 대체 동작은 `repeatUnit: row`로 구분한다. 저장된 자동 탐지 스펙은 detector=rowGroup으로 이전 동작을 판별한다. 그 밖에 repeatUnit이 없는 스펙은 block으로 처리한다.

원본 구간의 직계 셀 주소·행 병합·열 병합 형태를 매 반복 단위마다 복제한다. 선택 영역 내부에서 전체 행을 덮는 병합도 단위마다 별도의 셀이다. 반복 원본 밖으로 이어지는 병합은 상위 공통 셀로 남기고, 생성으로 늘거나 줄어든 행 수에 맞춰 범위를 조정한다. 대체 구간과 상위 병합 구간이 같더라도 원본 단위보다 큰 상위 병합은 통째로 복제하지 않는다. 월·주 안의 차시를 늘리는 경우 새 차시도 원래 월·주에 포함된다. 중첩 표 좌표는 독립적으로 보존한다.

## 월 → 주 → 차시 관계와 생성 데이터

저장·계획 편집용 배열은 기존과 동일한 최하위 행 객체 배열이다. 생성 시에는 원본 XML에서 병합 셀의 범위와 왼쪽 상위 셀의 포함 관계를 계산해 plan 스키마에 repeatBlock으로 함께 전달한다. 생성 서비스의 두 경로 모두 이 구조를 사용하며, 원본 예시 내용 제공 옵션을 꺼도 구조는 제공한다.

- AI는 완전한 반복 단위 행 수의 배수로 데이터를 생성한다.
- 같은 월/주 병합 구역의 행들에는 같은 상위 값을 기록하고, 그 아래 차시별 내용을 작성한다. 한 행 원본에서는 원본과 대체 구간, 그 위의 기존 병합 값도 생성 프롬프트에 전달한다.
- 병합 구역 안에서 상위 값이 바뀌거나 반복 단위 행 수가 맞지 않으면 계획 검증이 오류를 반환하고 기존 AI 재시도 경로로 교정한다.
- 병합 셀에 서로 다른 값을 줄바꿈으로 합치던 처리는 제거했다. 직접 입력한 데이터도 병합 구역 안에서 충돌하면 채움 오류를 반환한다.
- 과거 저장 데이터 또는 수동 입력이 마지막 반복 단위를 덜 채웠다면 문서의 병합 형태는 완전하게 유지하고 남은 입력 셀은 비운다. 원본 예시를 새 입력처럼 복제하지 않는다.

## 검증과 제한

편집 전후에 셀 주소, 격자 점유, 병합 경계, 겹침·빈 영역을 검사한다. 높이를 계산할 수 있는 경우 표 높이를 갱신한다. 실패한 rowGroup의 구조 변경은 반영하지 않는다. 앞 단계에서 다른 타깃에 적용된 편집까지 롤백하지는 않는다.

keepRows로 내부 행을 별도로 이동하는 기존 특수 스펙은 단일 행 대체 방식으로 처리한다. 반복 구간 경계가 병합 묶음을 일부만 자르는 변경, 내부 병합 묶음의 일부 행을 보존 행으로 이동하는 변경, 셀 영역 서식을 부분 반복하거나 통째로 삭제하는 변경은 오류를 반환한다. 같은 표의 여러 rowGroup locator를 일괄 재설계하는 변경은 포함하지 않는다.

회귀 테스트는 두 달을 생성했을 때 월 셀이 두 개인지, 각 반복 단위의 구조가 원본과 같은지, 주·차시의 포함 관계를 AI에 전달하는지, 상위 값 충돌을 검증하고 재시도하는지 확인한다. 기존 테스트 중 전체 월 병합 확장과 병합 값 줄바꿈을 정답으로 삼던 기대값은 잘못된 반복 의미를 고정하던 것이므로 수정했다.

```powershell
npx --yes tsx scripts/task-work-spec-test/run-form1.mts

```
