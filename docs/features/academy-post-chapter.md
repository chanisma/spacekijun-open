# 제4장 · 아침의 편지, 새로운 가능성

제3장을 완료한 학생이 처음 중앙 광장에 나오면 아침의 루온·리아 CG로 이야기를 시작한다. 실제 시계가 아침이 될 때까지 기다리게 하지는 않는다. 잠을 잘 잤는지 묻는 인사, 세린과 지낸 첫날 밤, 기록과 새 소식을 함께 읽는 이유를 대화로 연결한 후 전서구 우편국으로 이동한다. 우편국에 들어오는 CG부터 CHAPTER IV를 표시한다. 리아는 NPC에게 존댓말, 독백은 `thought: true`로 ‘리아 · 속마음’을 표시한다. [캐릭터 가이드](academy-characters.md)를 따른다.

## 진행과 실제 학습 기록

| 저장 단계 | 장면·필수 행동 |
| --- | --- |
| 0~12 | 아침 광장에서 루온과 대화, 12에서 우편국으로 이동 |
| 13~19 | 전서구 도착 CG, 루온·노엘 대화와 리아 소개 |
| 20 | 편지를 건네받는 CG → 편지함 → 추천 편지의 그림·기사 읽기 확인 |
| 21~22 | 노엘의 질문·예시 안내, 22에서 같은 기사의 실제 관측 일지 저장 |
| 23~29 | 작성한 일지 CG와 격려, 재방문·연구시설 연계 안내, 리아의 회상 |
| 30 | 완료 CG·50코인 보상, 노엘 일반 기능 해금 |

기존 `ai_news`의 공개 선별(`keep`) 기사 중 유효한 `comic_path`가 있는 기사를 게시일 내림차순·ID 내림차순으로 추천한다. 필터 검색 결과나 첫 페이지에 의존하지 않는다. 적합한 기사가 없으면 준비 중 안내와 재조회 버튼을 제공한다. 만화 이미지가 표시되지 않으면 기존 네 컷 대사 대체본을 읽을 수 있다. 편지의 그림·기사 영역 뒤 ‘그림과 기사를 읽었어요’로 읽기를 확인한다. 이후 해당 기사가 책갈피에 고정되어 새 기사가 도착해도 쓰던 일지는 바뀌지 않는다.

일지는 기존 `world_news_inquiries`에 학생 본인으로 저장한다. 필수값은 학생의 질문이며 예상·이유, 확인 방법, 발견·새 질문은 생각나는 만큼 적을 수 있다. 저장 후 서버는 챕터에서 읽은 기사 ID, 본인 소유, 읽기 이후 저장 시각, 비어 있지 않은 질문을 검사한다. 일지 저장에 실패하면 입력을 유지하고, 일지 저장 뒤 챕터 책갈피만 실패하면 ‘이미 저장한 일지로 노엘과 이어가기’로 복구한다. 이전 대사 감상은 저장 단계·보상을 변경하지 않는다. 관리자 미리보기는 선택 학생의 챕터를 읽고 진행·일지 쓰기는 막는다.

저장한 일지의 ‘관측 일지 삭제하기’에서 확인 후 질문·예상·계획·성찰 한 행을 삭제할 수 있다. 기존 본인 전용 RLS를 그대로 사용한다. 취소나 삭제 실패 시 내용은 남고, 성공 시 입력 초안과 조회 캐시를 비워 다시 열어도 삭제한 내용이 돌아오지 않는다. 내 일지 목록과 진행 중 챕터의 저장 복구 후보도 갱신한다. 이미 완료한 챕터 책갈피·당시 질문 스냅샷·50코인 보상은 유지한다.

## 해금과 연구시설 연계

우편국 입장은 제3장 이후 가능하다. 제4장 완료 전 노엘과 편지함/책상 표식은 현재 챕터를 안내하며 일반 NPC 메뉴, 기사 AI 대화, 노엘의 오늘의 만남은 열리지 않는다. 제4장 완료 후 일반 기능이 열린다. 중앙 광장 루온과 여정 메뉴도 현재 제4장을 안내한다.

제4장까지 완료하면 광장의 루온 대화에서 챕터 선택지를 제거하고 일상 인사·오늘의 격려·자유 대화를 제공한다. 여정 메뉴의 이전 챕터 감상은 유지한다.

‘이 질문을 들고 연구시설로 가기’는 게임 안 새 별 찾기 설계지로 이동한다. 기사명·출처·학생 일지는 질문칸에, 기사 요약은 `academy_news_context` 수동 참고 출처로 별도 전달한다. 긴 요약을 질문칸에 출력하지 않고 ‘기사 요약과 관측 일지가 함께 도착했어요’라고 안내한다. 요약이 없는 기사는 없다고 표시한다. 사용자는 기사 참고 자료를 뺄 수 있다.

직접 설계 API와 교수 대화 모두 기사 요약을 받으며 요약을 학생의 실제 활동으로 오인하지 않도록 참고 자료임을 명시한다. 요약은 탐구 초안·확정 설계의 기존 출처 스냅샷에도 보존한다. 교수 대화에서 일반 KG 기록의 길이 제한 때문에 기사 요약이 잘리지 않도록 별도로 전달한다.

새 별 찾기에서는 질문칸에 공백이 아닌 내용이 있거나 선택한 출처가 있으면 ‘교수와 새로운 별의 설계도 만들기’를 사용할 수 있다. 이 버튼을 ‘교수와 대화하며 설계하기’ 위에 배치하고 두 버튼은 같은 높이·너비·색상·서체를 사용한다. 과목·학생 연결, 미리보기, 요청 중 잠금 등 기존 조건은 유지한다. 편지 검색과 분류는 모바일에서도 같은 행의 44px 높이로 정렬한다.

## 배포·자산·검증

`20260914100000_academy_post_chapter.sql`은 제3장/보상 마이그레이션 이후 적용한다. 기존 챕터 테이블에 `post_first_letter`, 기사 참조·제목·읽기 시각을 추가하고 기존 학생/관리자 범위 읽기를 확장했다. 서버 전이 RPC는 revision과 동일 학생 단위 잠금을 사용한다. 기존 완료 트리거가 제4장 50코인을 한 번 지급한다. 기존 학생 기록·질문·보상 초기화는 하지 않는다. 연결 DB 적용·마이그레이션 이력 등록 및 `academy-npc` 챕터 안내 프롬프트 배포 완료. 프런트엔드 호스팅 배포는 별도로 필요하다.

내장 image_gen으로 기존 인물·공간 원화를 참조해 1536×1024 CG 네 장을 생성했다. 리아가 주체적으로 행동하고 루온·노엘이 곁에서 돕는다. CG는 전체 게임 화면을 채우며 화면 비율에 따라 가장자리는 잘릴 수 있다. 최종 자산과 정확한 프롬프트는 아래에 보관한다.

SQL 검사는 `supabase/tests/academy_post_chapter.sql`에서 실제 인증 역할로 선수 챕터, 최신 만화 기사, 읽기/일지 건너뛰기 방지, 저장 복구, 중복 없는 보상과 학생/관리자 권한을 검사한다. 제1~3장과 보상 SQL을 함께 실행한 호환 검사 및 적용 후 검사도 통과했다. 모든 SQL 테스트 데이터는 롤백했다. `scripts/academy-test/post-chapter-browser-checks.mjs`는 실제 React/Phaser와 가상 서비스로 30단계 진행, 대사 재개, 네 CG, 필터 크기, 실패·복구, 노엘 해금, 양쪽 설계 방식의 숨겨진 요약 전달과 관리자 미리보기를 검사한다. 긴 기사 요약·대화 출처 보존 및 캐릭터 말투 자동 검사도 통과했다.

최종 검증(2026-09-14): 기존 기숙사·공방·룸메이트·KG·교수 면담 등을 포함한 전체 브라우저 회귀 검사를 통과했다. 추가 요청인 일지 삭제·취소·실패 복구, 제4장 완료 후 루온 챕터 선택지 제거, 도서관 빈 페이지 제외까지 반영한 제1~4장 브라우저 검사도 통과했다. 대상 ESLint, 직접 설계/대화/기사 맥락/캐릭터 자동 검사, 프로덕션 빌드가 통과했다. 전체 앱 TypeScript 검사는 다른 영역의 기존 오류 230개가 남아 있으며 아카데미·요즘 세상 영역 오류는 없었다.
