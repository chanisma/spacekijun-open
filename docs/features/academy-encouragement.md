# 루온의 오늘의 격려

루온과 대화한 뒤 ‘루온의 오늘의 격려 듣기’를 선택하면 AI가 그날의 격려를 생성한다. 입장·일반 대화 메뉴를 여는 것만으로는 생성하지 않는다. 기존 일일 NPC 질문과 별도로 한국 시간 00:00 기준 하루 한 번 저장한다. 같은 날 재방문/새로고침은 같은 문장을 보여 준다.

완성 대사를 사전에 준비하지 않는다. 서버는 여섯 소재 중 하나를 무작위로 선택하고 Solar Pro 4가 2~3문장을 새로 쓴다. `voice.ts`는 다정하고 호기심 많으며 여유와 가벼운 장난기가 있는 루온의 성격, 리아와의 관계, 편안한 존댓말과 대사 예시를 제공한다. 날짜·오늘의 테마 소개, '리아님/당신', 자신을 3인칭으로 부르기, 상담사 같은 상투적인 응원 문구를 피하도록 한다. 최근 세 번의 격려를 참고해 반복 표현을 줄인다. 학업 성과나 감정을 안다고 꾸미거나 질문·퀴즈를 내지 않으며, 긍정적인 감정이나 AI 의존을 강요하지 않도록 지시한다. 결과는 루온의 현재 착용 외형을 반영한 큰 초상과 함께 표시한다.

생성 중에는 루온이 말을 생각하는 대사를 표시한다. 화면을 닫아도 서버 작업은 이어지고 다시 열면 저장 결과를 읽는다. 실패한 생성은 재시도할 수 있으며, 75초 lease와 토큰으로 동시 창·이전 작업의 늦은 응답을 막는다. 같은 날 성공한 결과는 다시 생성하지 않는다. 최근 30일 기록을 읽을 수 있다.

2026-09-13 말투 수정 요청에 따라 당시 저장 완료된 대사 1건을 백업 후 짧은 대화체로 교체했다. 소유자·날짜·원문이 일치하는 행의 `message`만 변경했고 상태와 생성 시각을 보존했다. 개인정보가 포함된 백업은 저장소에 추가하지 않았으며 로컬 TEMP의 `academy-luon-before-voice-20260913.json`에 보관한다. 이는 사용자가 요청한 일회성 편집으로, 일일 재생/생성 정책은 유지한다. 새 프롬프트의 실제 Solar 응답을 표본 확인하고 Edge Function에 반영했다. 대기 문구도 “아, 리아. 마침 잘 만났네요.”로 변경했다.

`academy_luon_encouragements`의 `(user_id,day)` 기본 키, `academy_encouragement_claim/finish` service-role 전용 invoker RPC를 사용한다. 날짜와 소유자는 서버에서 결정한다. 프런트엔드는 응답 생성·수정·삭제 권한이 없고 학생은 본인 결과만 읽는다. 관리자 미리보기는 실제 역할과 선택 학생을 확인해 읽기만 허용한다. 생성 endpoint는 JWT를 검증하고 학생 역할을 재확인한다.

`20260913171540_academy_luon_encouragement.sql`과 `academy-encouragement` Edge Function 적용 완료. 서버 단위 테스트와 실제 DB 역할/lease/재시도/일일 재생 테스트(`supabase/tests/academy_encouragement.sql`, 롤백)를 수행했다. UI 검증은 실제 React 화면과 저장 fixture를 사용하며 실사용 학생의 모델 응답 품질 검증과 구분한다.

검증 결과: 관련 자동 테스트 35개와 대상 ESLint, 프로덕션 빌드 통과. 전체 앱 타입 검사는 기존 다른 영역 오류 230개가 남아 있으며 이번 아카데미 변경 파일 오류는 없다. DB 역할 검사는 롤백했고, 새 기능 관련 보안·성능 Advisor 지적은 없었다. 프런트엔드 호스팅 배포는 하지 않았다.
