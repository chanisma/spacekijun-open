# 왕립 도서관 자습 기록장

왕립 도서관의 ‘자습 기록장 펼치기’ 또는 엘리안 대화의 ‘내 자습 참여 기록과 보상 확인하기’에서 연다. 기존 자습 화면으로 이동하지 않고 게임 화면 안의 양피지 기록장으로 주별 이력을 보여 준다. 왼쪽 주 선택과 오른쪽 본문은 독립적으로 스크롤하며 스크롤바는 숨긴다. 모바일에서는 주 선택을 상단으로 배치한다.

2026년 9월 7일 월요일부터 한국 시간 기준 월~일 단위로 기록한다. 현재 주까지 이동하며 날짜·열람실·교시·등록된 시작/종료 시각·참석 상태·보상 수령 여부를 표시한다. 합계는 참석이 확인된 교시의 시간이며 실제 체류 시간을 측정한 값이 아니다. `operating_periods`에 시간 정보가 없으면 시간을 만들지 않고 합계 제외 회차를 안내한다. 과거 교시 시간의 별도 스냅샷이 없어 현재 열람실 설정을 사용한다.

기존 `seat_reservations`와 `study_rooms`를 읽는다. `attendance_status=attended` 또는 구형 기록의 `attendance_status IS NULL AND is_attended=true`만 참석으로 인정한다. `is_attended=true`인 사유 결석·보충 대상은 제외한다. 미래 날짜는 보상 대상으로 삼지 않는다. 원본 출석·예약 정보를 복사하거나 출석 여부를 이 기능에서 수정하지 않는다.

학생이 해당 주의 보상 버튼을 선택하면 아직 받지 않은 참석 회차당 아카데미 코인 5개를 지급한다. 기존 공방 지갑 `academy_user_stats.coins`에 합산하며 자습 서비스의 `point_transactions`나 10포인트 출석 트리거는 변경하지 않는다. 화면을 여는 것만으로 자동 지급하지 않는다.

`academy_study_rewards.reservation_id` 기본 키로 재시도·여러 창의 중복 지급을 방지한다. 원본 예약이 삭제되어도 지급 원장을 보존하며 이미 지급된 보상을 자동 회수하지 않는다. 원장은 학생 직접 쓰기를 막고, 읽기도 본인으로 제한한다. 권한을 검사하는 private 함수와 public invoker RPC만 사용한다. 수령 함수는 `auth.uid()`로 학생을 결정하고 서버에서 회차와 금액을 계산하며, 예약 행 잠금과 기존 지갑 advisory lock으로 정산을 직렬화한다. 관리자 미리보기는 선택 학생 기록만 읽고 보상은 수령할 수 없다.

기존 출석 보호 트리거에 더해, 이미 출석 정보가 있는 예약의 ID·학생·열람실·날짜·교시를 학생이 바꿔 새로운 보상을 만들지 못하도록 `academy_protect_study_identity`를 추가했다. 교사/관리자의 정정과 학생의 피드백 작성은 허용한다. 다른 예약 권한은 변경하지 않는다.

`20260913171542_academy_library_study_rewards.sql` 적용 완료. `supabase/tests/academy_study.sql`에서 실제 역할로 주 경계, 시간 합계, 결석/보충/미확인 제외, 구형 출석, 5코인 정산·재시도, 날짜/ID/출석 위조 방지, 타 학생 비공개, 관리자 읽기 전용, Seaton 포인트 불변을 검사하고 롤백했다. 브라우저 검증은 실제 React/Phaser 화면에 저장 fixture를 연결하며 실사용 학생에게 보상을 지급하지 않는다.

검증 완료: 대상 ESLint와 프로덕션 빌드, 데스크톱·모바일 브라우저 회귀 검사 통과. 전체 타입 검사에는 기존 다른 기능의 오류 230개가 남아 있으며 아카데미 파일 오류는 없다. 보안·성능 Advisor의 새 자습 기능 관련 지적은 0건이다. 적용 후 지급 원장은 0건으로, 실사용 보상을 테스트에서 지급하지 않았음을 확인했다. 프런트엔드 호스팅 배포는 하지 않았다.
