# 연구대 설계 개선 (2026-09-13)

- 아카데미의 수업 목록은 기존 탐구설계의 `useCurriculumSubjects`와 `synthesizeTargetFromCurriculum`을 공유한다. 학생 본인의 교과 이력·확정 편성·수요조사·지정 과목을 사용하며, 이수 중/이수 완료/편성 확정/지정/신청 및 학년도·학년·학기를 표시한다. 학교의 현재 개설 과목만으로 개인의 이수 상태를 추측하지 않는다. 창체 활동 선택은 유지한다.
- 교수 대화 버튼을 보라색·금색의 큰 버튼으로 강조하고, 질문 입력 안내와 버튼 아래에 질문을 아직 정하지 않아도 대화로 시작할 수 있음을 설명한다.
- 아카데미 및 기존 탐구설계에서 성취기준 맥락을 사용/사용 안 함으로 선택한다. 기본은 사용 안 함. 기존 `docgen_context`의 성취기준 분류와 접근 권한을 그대로 사용하고 새 테이블을 만들지 않는다.
- 선택한 참고 자료는 직접 설계와 교수 대화 모두에 전달된다. 대화에서는 서버로 보낼 첫 메시지의 사본에만 참고 자료를 첨부하여 학생의 실제 대화 기록과 섞지 않는다. 교육과정은 참고이며 탐구 범위를 제한하거나 학생의 실제 경험으로 취급하지 않는다.
- 사용을 선택한 본문을 읽지 못하면 재시도 또는 사용 안 함으로 변경하도록 안내하며, 조용히 참고 자료 없이 AI를 호출하지 않는다. 해당 과목에 등록된 맥락이 없으면 선택을 비활성화한다.
- 연구대 KG에 기존 `InquiryGraphCanvas.preview`를 연결해 분석 응답 즉시 미리보기 별과 관계선을 표시한다. 임시 보관 응답을 기다리지 않으며, 같은 초안이 자동 저장된 후 중복으로 그려지지 않도록 해당 draft ID를 제외한다. 학생이 설계지를 접어 확대·검색하며 살펴볼 수 있다. 확정된 설계는 기존 저장/이력 경로로 전환된다.

## 검증

`scripts/academy-test/browser.mjs`에서 학생별 이수 상태, 기본 맥락 끔/대화 및 설계의 맥락 켬, 확정 전 새 별 검색, 기존 대화 저장 흐름을 검증한다. `scripts/inquiry-panel-layout-test/run.mjs`는 기존 탐구설계의 맥락 선택과 결과 생성 이후 잠금, 패널 배치를 검증한다. 브라우저 검증은 가상 데이터로 실행하며 실제 학생 기록이나 AI 사용량을 변경하지 않는다.
