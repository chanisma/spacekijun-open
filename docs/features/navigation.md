**외부 메뉴 배치(placement, 2026-08-05)**: 외부 메뉴(`resource` type='iframe'|'link')는 기본적으로 [외부 연결] 섹션의 "외부 메뉴" 서랍에 모이지만, 관리자가 메뉴별로 다른 카테고리에 넣을 수 있다. 저장 위치 = `resource.meta.placement`(교사 네비)·`meta.studentPlacement`(학생 네비), 값 형식 = `'external'`(기본) | `'section:<id>'` | `'group:<id>'`. 선택지 카탈로그·해석기(`teacherNavPlacements`/`studentNavPlacements`/`placeNavItem`)는 **`config/navigation.ts` 단일 출처**이고, 그룹 지정은 `NavGroup.id`(표시명 `name`이 아니라 안정 식별자)로 한다. **대상을 못 찾으면 기본 서랍으로 조용히 폴백** — 권한 때문에 섹션이 주입되지 않은 사용자(예: admin 전용 [학습])에게 메뉴가 통째로 사라지지 않게 하는 안전장치라, [학습]·[관리] 섹션은 카탈로그에서 의도적으로 제외했다. **`useNavSections`에서 배치는 `applyMobileLayout` 다음에 수행**해야 한다(배치는 섹션 끝 append라 순서가 반대면 [오늘]에 넣은 외부 메뉴가 입시정보를 밀어내 모바일 하단 5칸 구성이 깨진다). 모바일 하단 5칸은 `item.isExternal`이면 `<a>`로 렌더(절대 URL은 react-router `Link`로 열 수 없음). **주의: `meta`는 생성·수정 시 통째로 교체**되므로 새 필드는 반드시 `useIframeMenus.ts`의 `buildMenuMeta`에 넣어야 하며, 순서 변경처럼 폼 전체를 보지 않는 경로는 병합 mutation(`updateIframeMenuOrder`)을 써야 한다. 관리 UI = Admin "외부 메뉴 관리"(`IframeManagement.tsx`, 추가·수정 폼은 `MenuFormFields` 공용). 회귀 = `scripts/nav-placement-test/run.mts`
