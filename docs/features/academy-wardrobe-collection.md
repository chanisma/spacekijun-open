# 아카데미 삽화 수집·전체 NPC 의상·연구 수첩 정리 (2026-09-14)

## 학생 화면

- 여정과 소지품의 세린과 나를 알아가기는 SIDE STORY 카드로 표시하며 제3장 완료 조건을 유지한다.
- 프롤로그 다시 감상하기 위에 수집한 삽화 보기를 제공한다. 전체 19장: 프롤로그 6장, 제1장 3장, 제2장 3장, 제3장 3장, 제4장 4장. 챕터 책갈피가 도달한 장면만 공개하고 반복 삽화는 한 장으로 합친다.
- 프롤로그를 완료하거나 건너뛰어 다시 감상이 열린 경우 6장 모두 공개한다. 과거 첫 장면에서 건너뛴 기록에도 적용되며 별도 데이터 수정은 없다. 미완료 프롤로그는 도달한 장면까지만 공개한다. 다시 감상할 때 최대로 본 위치를 저장하고 원래 완료 날짜와 건너뛰기 선택은 유지한다.
- 게임 화면 안에서 분류·목록·이전/다음·키보드 이동을 제공한다. 큰 그림은 contain으로 전체가 보인다. 관리자 미리보기는 선택 학생의 챕터 기록만 사용하며 관리자 본인의 프롤로그를 혼합하지 않는다.
- 옷장과 맞춤 주문의 대상은 리아·루온·카시안·엘리안·노엘·세린·기숙사 방이다. 원화 참조를 각 인물에 맞게 지정하고 얼굴·체형·정체성을 보존하면서 의상과 헤어스타일을 변경한다. 인물 결과물은 기존 투명 PNG 검증을 통과해야 한다.
- 캐릭터별 장착을 독립적으로 저장하고 각 공간의 인물, 대화, 챕터의 인물 초상과 기숙사 세린에 적용한다. 고정된 스토리 삽화는 수집 원화 그대로 감상한다.
- 연구 수첩의 탐구 기록 및 별자리 조언을 확인 후 삭제한다. 기존 inquiry-design 삭제 서비스와 권한을 사용하고 연구 workspace를 갱신한다. 실제 활동 기록은 삭제하지 않는다. 관리자 학생 미리보기에는 삭제 버튼을 제공하지 않는다.
- 새 별 찾기 질문 예시는 실험·보고서·발표 등 원하는 활동 형태도 함께 적도록 안내한다.

## 연구 수첩에서 후속 탐구 시작

연구 수첩의 각 탐구 기록에서 `새 별 찾기에서 이어가기`를 선택하면 연구대 설계지로 이동한다. 저장된 탐구 질문과 성찰은 편집 가능한 질문 칸에 표시하고 전체 설계·선택 이유·참고 자료는 별도 수첩 맥락으로 전달한다. 이전 수업/활동과 학년·학기를 우선 일치시키며 찾을 수 없으면 수업 선택 확인을 안내한다. 교수 대화 및 직접 설계 두 경로 모두 이 자료를 사용하고 새 설계에도 출처를 보관한다.

이전 KG의 ID를 현재 그래프 노드로 재사용하지 않는다. 원래 설계와 연결된 실제 활동은 유지하며 새로운 설계로 저장한다. 여러 번 이어갈 때 조상 설계 맥락 전체를 중첩 복사하지 않는다. 관리자 학생 미리보기는 이어가기 쓰기 동작을 제공하지 않는다. 새 DB 마이그레이션은 필요 없다.

검증: researchContinuation.test.ts에서 과목 일치, 전체 성찰 보존, 예전 KG ID 비재사용, 중첩 제거와 원본 보존 검증. 실제 브라우저에서 수첩→설계지→교수 대화 및 직접 설계의 자료 전달과 원본 유지 검증 통과.

## 방 꾸미기 칸에서는 방만 보인다 (2026-09-14)

옷장의 미리보기(`fitting`)는 방 원화 위에 사람 원화를 겹쳐 그리는데, 종전엔 사람 칸이 아닌 **방 꾸미기·이전 소장품** 칸에서도 `preview['ria']` 로 폴백해 방 위에 리아가 함께 그려졌다(사용자 지적). 지금은 그 두 칸에서 사람 이미지를 아예 그리지 않는다 — 방 꾸미기의 미리보기 대상은 방이지 리아가 아니다. 사람 칸(리아·루온·교수·사서·우체국장·세린)은 종전과 같다.

## 기본 의상·기본 방 타일 (2026-09-14)

옷장의 사람 칸·방 칸 **맨 앞에 기본 모습 타일**을 둔다(사용자 지시). 종전엔 소장한 물건만 나열돼 "처음 모습으로 돌아가기"가 입고 있는 물건을 골라 [기본 모습으로 돌아가기]를 누르는 경로뿐이었고, 아무것도 안 산 칸은 빈 목록이었다. 타일의 그림은 카탈로그 행이 아니라 `workshopReference` 원화라 **별도 선택 상태(`baseSelected`)** 로 다룬다 — 고르면 미리보기가 기본 원화로 바뀌고, 그 칸에 입고 있는 물건이 있으면 [기본 의상으로 갈아입기]/[기본 방으로 되돌리기]가 그 물건을 `unequip` 한다(새 RPC 없음). 없으면 "지금 이 모습이에요". 공방(shop) 뷰와 이전 소장품 칸에는 그리지 않는다.
