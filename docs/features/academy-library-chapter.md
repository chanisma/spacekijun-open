# 제2장 · 이야기 속에서 자라는 질문

제1장을 마친 학생이 처음 중앙 광장에 나오면 루온이 말을 건다. 한때 자신의 하늘만 비어 있는 듯 느꼈다는 경험과 도서관 기록에서 질문을 찾게 된 이야기를 들려준 후 왕립 도서관으로 동행한다. 도서관 전경 CG에서 제2장 제목이 등장한다.

엘리안의 환영, 루온과의 짧은 농담, 첫 탐구를 설계한 리아의 방문 이유, 책장 안내가 이어진다. 수많은 책에 놀라는 리아의 CG를 본 뒤 실제 창체 아카이브 책장이 열린다. 학생은 분야별 책을 펼치고 목차의 활동을 선택해 해당 자료를 읽는다. 활동의 시작·탐구와 활동·발견과 성과 중 내용이 비어 있거나 공백뿐인 항목은 페이지로 만들지 않는다. 실제 내용이 있는 페이지 어디서든 궁금한 점이 생기면 질문 기록으로 이어갈 수 있으며 세 페이지 열람을 강제하지 않는다. 본문이 전혀 없는 활동은 다른 자료를 선택하도록 안내한다. 그 활동의 ID와 제목을 기록한 후 질문과 궁금해진 이유를 각각 10~1,000자로 작성한다. 저장이 성공해야 마지막 대화와 완료로 진행할 수 있다.

리아는 다른 사람의 기록이 자신의 질문으로 이어진다는 점에 놀라며 언젠가 자신의 이야기를 남기겠다고 말한다. 엘리안은 기록을 언제든 참고하고 새로운 이야기를 제안하러 오라고 권한다. 완료 화면에서 실제 저장한 질문/이유를 다시 읽고 책장 또는 제안서로 이동할 수 있다.

## 저장과 권한

`20260913171544_academy_library_chapter.sql`은 `academy_chapters`의 기본 키를 `(user_id, chapter)`로 확장한다. 기존 제1장 행을 보존하며, `first_star`의 0~16과 `library_questions`의 0~18을 분리한다. 제2장에는 활동 ID/제목, 질문, 궁금해진 이유가 추가된다. 첫 광장 만남은 `start` 요청으로 0번 책갈피를 저장하며 중복 요청은 재시작하지 않는다. 읽기 API는 행을 만들지 않는다.

첫 장 완료 여부와 순차 진행, 동일 revision 재시도, 활동의 학생 열람 권한을 DB에서 확인한다. 질문과 이유 저장은 진행 갱신과 원자적으로 이루어진다. 관리자 학생 미리보기는 읽기만 가능하다. 기존 튜토리얼/첫 의뢰 기록은 삭제하거나 완료 처리하지 않는다. 기존 연속 의뢰는 과거 완료 기록 또는 제2장 완료 시 작성한 실제 질문으로 시작할 수 있다.

**교직원 체험에서 'read' 가 거부되던 결함 (2026-09-14, `20260914150000_academy_library_staff_read.sql`)**: 교사·관리자가 체험으로 도서관 챕터를 진행해 책의 활동에서 [나만의 질문 발견하기]를 누르면 '열람할 수 있는 책의 활동을 골라 주세요.'(42501)가 났다. DEFINER 함수의 열람 가드가 "`activity_select` 와 같은 규칙" 을 손으로 옮겨 적으면서 세 분기 중 **교사·admin 분기(`is_teacher_or_admin`)를 빠뜨렸고**, 학생만 게임을 하던 때는 드러나지 않다가 교직원 체험이 생기며 터졌다. 클라이언트 책장은 정책대로 활동 1,593개가 전부 보이는데 서버만 거부하니 "골랐는데 고르라고 한다" 로 보인다. 지금은 정책과 같은 세 분기이고 권한은 넓어지지 않는다. **정책을 DEFINER 함수에 베껴 쓸 때는 분기 수를 세어 대조할 것** — RLS 는 자동 적용되지 않으므로 빠진 분기는 오류가 아니라 "화면에는 보이는데 서버가 거부" 로 나타난다.

## 챕터에 따른 메뉴

- 제1장 완료 전: 카시안의 오늘의 만남, 루온의 격려/자유 대화 등 후속 대화는 표시하지 않는다. 제2장 버튼도 표시하지 않는다.
- 제1장 완료 후: 제2장 이야기와 연구시설 후속 대화를 사용할 수 있다.
- 제2장 완료 후: 엘리안 후속 대화, 새 이야기 제안, 자습 이력, 연속 의뢰가 표시된다.
- 기숙사 챕터는 아직 미구현이므로 세린의 자기이해 및 대화 버튼은 여정 메뉴와 기숙사에서 숨긴다. 캐릭터는 방에 남는다. 기존 검사 데이터와 기능 구현은 보존한다.
- 기존 ‘여행 수첩 펼치기’, 첫 의뢰 수락, 독립적인 튜토리얼 체크리스트는 제거한다. 질문 기록은 제2장 중에 열리고 이후 완료한 장에서 다시 읽는다. 루온의 안내는 현재 챕터 목표를 가리킨다.

## 이미지와 검증

내장 imagegen으로 기존 리아·루온과 도서관을 참고하여 `chapter-library-arrival.png`, `chapter-library-shelves.png`를 생성했다. 프롬프트는 `public/images/academy-game/manifest-library-chapter.json`에 기록한다. 기본 의상 CG이며 대화 입상은 실제 착용한 의상을 사용한다.

DB 역할/단계/활동/노트/연속 의뢰 테스트: `supabase/tests/academy_library_chapter.sql` (전체 롤백). 브라우저: `scripts/academy-test/library-chapter-browser-checks.mjs` (실제 서비스 호출 없는 가상 데이터), 기존 아카데미 회귀 검사에 포함.

검증 현황: 연결 DB에 마이그레이션 적용 및 이력 등록 완료. 제1장 호환성·제2장 권한/순서/노트/연속 의뢰 검사를 모두 통과하고 테스트 행 변경은 롤백했다. DB Advisor의 새 챕터 관련 지적은 0건이다. 기존 아카데미 자동 검사 35개, 기존 탐구설계 패널 검사와 전체 아카데미 브라우저 회귀 검사를 통과했다. 전체 앱 타입 검사는 다른 영역의 기존 오류가 남아 있으며 이번 수정 영역의 타입 오류는 없다. 프런트엔드 호스팅 배포는 수행하지 않았다.

최종 추가 확인: 다른 창에서 노트 이후 여러 장면을 진행한 경우 현재 챕터로 복귀하여 빈 화면에 멈추지 않는다. 관리자 미리보기의 제2장 기록 버튼이 비활성화되고, 제1장 완료 효과는 동작 줄이기 설정에서 정적으로 바뀐다. 최신 프로덕션 빌드와 챕터 집중 재검사 통과.

## 대사 재감상과 안내 보완

루온의 챕터 안내를 단계별 구어체 대사로 교체했다. 제1장·제2장에 이전 대사/다음 대사/현재 진행으로 돌아가기를 추가했다. 재감상은 화면상의 위치만 바꾸며 저장한 진행, 행동 및 보상을 재실행하지 않는다. 제2장 완료 뒤 엘리안의 질문 다시 보기 선택지는 제거했다.

막간 시작 저장이 실패하면 첫 장면에서 책갈피 저장을 재시도할 수 있다. 제2장 쓰기 전에 진행 조회를 취소해 앞선 조회가 새 책갈피를 덮어쓰지 않도록 했고, 챕터를 새로 열 때 이전 오류 표시를 정리한다. 사용자가 보고한 오류의 정확한 문구는 확인되지 않아 동일 원인인지 단정하지 않는다.

제2장을 처음 완료하면 50코인을 지급하고 완료 화면에 표시한다. 기존 완료에도 한 번 소급 적용한다. 별도로 보고된 카시안 연속 의뢰의 users 권한 오류는 서버 RPC의 프로필 조회로 수정했다. [보상·권한 수정 상세](academy-chapter-rewards.md).

2026-09-14: 빈 항목은 페이지에서 제외하며 실제 내용이 있는 어느 페이지에서든 질문 발견으로 진행한다. 브라우저 검사에서 모든 본문이 빈 자료의 안내와 진행 버튼 숨김, 시작/성과가 비어 본문 한 페이지만 남은 자료의 제2장 진행을 확인했다. 페이지 수는 챕터의 완료 조건이 아니다.
