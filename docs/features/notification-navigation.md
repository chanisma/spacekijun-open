# 알림에서 관련 정보 이동

알림 카드의 하단 버튼을 누르면 관련 화면으로 이동하고, 미확인 알림은 읽음 처리한다.

| 알림 | 버튼 | 이동 대상 |
| --- | --- | --- |
| 구매 신청 | 신청 확인 | `meta.purchase_page_id`의 구매 게시판 |
| 전자서명 | 서명 확인 | `meta.signature_request_id`의 서명 상세 |
| 창체 성찰 요청·성찰 도착·피드백 | 활동 확인 | `meta.activity_id`의 활동 상세 |
| 수업 교체 승인·거절·취소 | 시간표 확인 | `meta.swap_date`가 가리키는 주의 시간표 (날짜가 없으면 이번 주) |
| 일정 취소 | 일정표 확인 | 일정표 (삭제되었을 수 있어 상세 조회 생략) |
| 관련 일정이 있는 기타 알림 | 일정 확인 | `related_meeting_id`의 일정 상세 및 해당 월 |

수업 교체 요청의 기존 승인/거절 버튼은 유지한다. 상세 연결에 필요한 ID가 없는 알림에는 상세 이동 버튼을 표시하지 않는다.

전자서명 화면은 `?request=<id>`를 단건 조회 후 상세로 열고 쿼리 파라미터를 소비한다. 삭제되었거나 접근할 수 없는 요청은 오류 안내를 표시한다. 기존 조회 권한과 상세 화면의 서명 가능 여부 판정을 그대로 사용한다.

DB 스키마 및 알림 생성 데이터 변경은 없다.
