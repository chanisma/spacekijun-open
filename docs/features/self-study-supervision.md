# 자습 감독 배정 (2026-10-11)

스케줄 › [부가 기능] › **자습 감독 배정**. 학년부장·담임이 자기 학년의 한 달 자습 감독을 공정한 규칙으로 초안 잡고, 고친 뒤 일정으로 만든다. 감독을 맡은 선생님끼리 교체를 신청·수락할 수 있다.

## 사용자 결정 (2026-10-11)

| 질문 | 결정 |
|---|---|
| 감독 한 칸 | **학년·하루 1명** — 3학년 열람실이 넷이어도 한 명이 순회 |
| 대상 시간 | 아침(월~금) · 저녁(월~금) · 토요일(3학년) |
| 아침 | 화면에서 고른다 — «저녁과 다른 사람» 또는 «그날 저녁 감독이 함께» |
| 공정 기준 | **누적 횟수 균등 + 요일 분산** (급식지도의 «이어지는 순환»이 아니다) |
| 교체 | **상대가 수락하면 바로** — 학년부장 승인 없음, 알림만 |
| 시험일 | 배정하되 날짜 옆에 시험 이름을 적는다 |
| 학년별 행사 | NEIS 에 학년 구분이 사실상 없어 판정하지 않는다(메모로만) |

## 누가 쓰나

- **배정하기** 탭: 태그 `N학년 부장`(학년부장) 또는 `N학년 N반`(담임)이 있으면 그 학년. 관리자는 전 학년. 교사 시점 미리보기에서는 미리보기 태그를 따른다.
- **내 감독·교체** 탭: 학생·직원을 뺀 교직원 누구나(감독을 맡은 사람이면 쓴다).
- 감독 대상(pool) = 그 학년도 `N학년부` 부서 소속 ∪ 그 학년 담임·학년부장 태그 보유자(부서 명단이 비어도 빠지지 않게). 이번 달만 빼야 할 사람은 화면에서 체크 해제(저장되지 않음).

## 규칙 (`src/lib/selfStudySupervision.ts`)

1. **시간대는 seaton 열람실에서** — 운영 중인 `study_rooms` 중 그 학년이 든 방. 이름에 `아침` = 아침(seaton 통계 계약 `seaton_private.facts` 와 같은 규칙, 교시가 없어 시간은 기본 07:40~08:20을 화면에서 고친다) · 운영 요일이 토요일뿐 = 토요일 · 나머지 평일 방 = 저녁. 시간은 교시의 처음~끝(저녁 18:40~21:40, 토요일 09:00~17:00).
2. **칸** — 평일 수업일·시험일 = 아침(+따로 모드)·저녁, 토요일 = 토요 자습, 일요일·공휴일·휴업일·방학 = 없음(`schoolDay.ts`). 오늘 이전과 이미 일정이 있는 칸은 만들지 않는다.
3. **후보 순서** — ①그 시간대 학년도 누적이 적은 사람 ②전체 누적이 적은 사람 ③그 요일을 덜 맡은 사람 ④어제·내일 맡지 않은 사람 ⑤마지막 감독이 오래된 사람 ⑥결정적 동점 순번(`달|학년` 시드 — 다시 눌러도 같은 초안, 달이 바뀌면 동점 순서가 바뀐다).
   - 시간대를 **따로** 세는 이유: 토요일 8시간과 아침 40분을 한 숫자로 섞으면 «횟수는 같은데 부담은 다른» 배정이 공정해 보인다.
4. 한 사람이 같은 날 두 칸을 맡지 않는다. 보이는 출장·연수가 있는 사람은 피하고, 모두가 막히면 **빈칸으로 두고 알린다**(조용히 규칙을 어겨 채우지 않는다 — 급식지도와 같은 결정).

## 화면

- 칸마다 사람 선택(후보는 위 순서, 옆에 시간대·합계 횟수), «빼기», 문제 표시(빈칸·같은 날 두 칸 = 로즈, 출장·연수·이틀 연속 = 앰버). 빈칸·중복이 있으면 만들기 버튼이 막히고 이유를 말한다.
- «사람별 횟수» = 학년도 누적 + 이 초안(시간대별·합계·요일 분포).
- 만들기는 두 번 누른다(담당자에게 알림이 가는 일괄 동작). `useSchedule.createEvent` 를 한 건씩 — 알림·담당자 정규화가 다른 업무 일정과 같은 경로.

## 교체

- 내가 담당자인 앞으로의 감독마다 [교체 신청] → «다른 감독과 맞바꾸기»(같은 학년, 앞으로 석 달) 또는 «대신 맡아 달라고 하기»(그 학년 대상자) + 전할 말.
- 받은 사람은 알림(→ `/schedule?supervision=swap`) 또는 [부가 기능] 버튼 배지로 들어와 수락/거절. 수락 순간 서버가 두 일정의 담당자·제목을 맞바꾸고, 신청자와 학년부장에게 알린다.

## 조용히 틀리는 자리

- **duty 행 RLS** — 감독 일정은 만든 사람·담당자에게만 보인다. 누적 횟수를 `meeting` 에서 직접 세면 다른 선생님이 만든 감독이 빠져 **오류 없이** 공정성이 무너진다 → `get_self_study_supervision_history` RPC.
- **교체는 클라이언트가 할 수 없다** — duty UPDATE 는 만든 사람만 된다. 서버가 두 일정을 잠그고 «신청 뒤 담당자가 바뀌지 않았는가»를 다시 확인한 뒤 바꾼다.
- **제목의 이름 자리** — 맨 끝 ` · 이름` 만 바꾼다. `replace` 로 이름을 찾으면 `김민` 이 `정시우` 안에서 걸린다.
- **`토요휴업일`** — 매주 토요일의 `휴업일` 이다. 닫힘으로 세면 토요 자습이 영원히 안 잡힌다(`schoolDay.isClosingEntry`).
- **다음 달이 다음 학기** — 학사력 기간을 적용하면 학기 밖이 «방학»으로 덮인다. 그래서 `applyTerm: false` 이고 방학은 NEIS 학사일정이 말한다.
- **`notification_events.priority`** — CHECK 가 `low·medium·high` 만 받는다. 처음 `normal` 로 썼다가 드라이런에서 잡았다(그대로면 모든 신청이 롤백).

## 회귀

- `npx tsx scripts/self-study-supervision-test/run.mts` — 열람실→시간대, 누가 배정하나, 칸(공휴일·시험·토요휴업일), 공정성(시간대별 차이 ≤1, 요일 몰림, 누적 반영, 출장 피하기, 빈칸), 전 학년 아침(수능일 찾기·수능 이후 3학년 제외), 못 하는 날(매주·날짜·기간·«함께» 모드), 배선(RPC·RLS 계약)
- `node scripts/self-study-supervision-test/run-screenshots.mjs` — 실제 모달 390·1280(자료 훅만 스텁) — 못 하는 날 서랍·전 학년 아침 포함 10장

## 전 학년 아침 · 못 하는 날 (2026-10-12)

**전 학년 아침(통합 당번)** — 아침 열람실은 학년을 넘나든다(운영: `[아침] 열람실 2` = 1·2·3학년, 3·4 = 1·2학년). 그래서 아침 감독을 학년마다 따로 뽑지 않고 세 학년 선생님을 **한 명단**으로 돌리는 방식을 선택지로 더했다.
- 배정하기의 학년 칩 끝에 **[전 학년 아침]** — 배정할 수 있는 사람(학년부장·담임·관리자)이면 누구나. 명단 = 1·2·3학년부 + 담임·학년부장 태그의 합(두 학년에 걸친 사람은 한 번). 아침 열람실 = 학년을 가리지 않고 전부. 학사일정은 학교 전체로 판정한다.
- 감독 일정 표지 `meta.supervision.grade = 0`(`SCHOOL_GRADE`), 제목 `자습감독 · 전 학년 아침 · 이름`. 이력 RPC 를 `p_grade = 0` 으로 그대로 읽고, 누적 횟수도 통합 당번끼리 센다.
- 학년 화면의 아침 방식에 **«전 학년 통합 당번»** — 그 학년에는 아침 칸을 만들지 않는다. 이 학년도에 통합 당번을 쓴 적이 있으면 이것이 기본값(저장하지 않는다 — 운영 방식은 이미 만든 일정이 말한다). «따로» 모드여도 그날 통합 당번이 이미 있으면 아침 칸을 또 만들지 않는다.
- **수능 이후 3학년 제외** — 기본 시작일 = 그 학년도 학사일정의 `대학수학능력시험`(낱말 `수능` 포함으로 찾지 않는다 — «수능 50일 응원»이 걸린다). 날짜를 고칠 수 있고 끌 수 있다. 3학년 = 3학년부·3학년 담임·학년부장 태그에 든 사람. 화면이 만드는 «자동» 규칙이라 저장하지 않는다.
- 교체: 통합 당번끼리만 맞바꾸고, 교체 완료 알림은 **세 학년부장 모두**에게. `supervision_swap_request.grade` CHECK 를 0 까지 넓혔다.

**못 하는 날(`supervision_unavailability`, 저장)** — 개인 사정은 시스템이 모르므로 적어 두게 했다.
- 두 모양: **매주**(요일 + 시간대, 선택적 «언제까지» — 예: 매주 수요일 저녁, 대학원 수업) · **특정 날짜**(날짜 + 시간대). DB CHECK 가 둘 중 하나만 받는다.
- 자동 배정은 출장·연수와 똑같이 **피하고**, 아무도 없으면 빈칸으로 둔다. 손으로 넣으면 앰버 «못 하는 날»(확인) 표시 — 사정이 바뀌었을 수 있어 막지는 않는다. 선택 목록에서 못 하는 사람은 맨 뒤 + «못 함: 사유».
- «그날 저녁 감독이 함께» 모드의 저녁 칸은 아침도 덮으므로, 아침에 못 하는 사람도 피한다(`cellSlots`).
- 적는 곳 둘: 배정하기 [못 하는 날] 서랍(그 명단 누구든) · [내 감독·교체] «내가 못 하는 날»(본인). 쓰기 RLS = **본인 또는 교사·관리자**(배정하는 학년부장·담임이 대신 적는다), 직원은 본인만, 읽기 = 교직원. 이미 만든 감독은 바뀌지 않는다(교체로).
- 규칙은 **이름**으로 맞춘다(배정·이력이 이름으로 돌아간다) — 저장은 resource_id, 조회 때 resource 이름을 붙인다.

### 조용히 틀리는 자리 (추가)

- 못 하는 날 **삭제는 행 수를 확인**한다 — RLS 가 남의 행을 0행 삭제로 조용히 거른다(직원이 남의 행을 지우려 하면 오류 없이 0행).
- 통합 당번 화면의 학사일정에 학년을 넘기지 말 것 — 2학년만 수학여행인 날에도 1·3학년 아침 자습은 있다.

## 출력 (2026-10-11)

[배정하기] 푸터의 [출력] → 새 창에 A4 가로 문서. 그 달 달력(이미 만든 감독 + 지금 초안, 칸마다 아침·저녁·토요일, 쉬는 날은 이유) 한 장. 선생님별 표는 사용자 결정으로 뺐다. 토요 자습이 켜져 있으면 월~토 달력. 급식지도 명단 창에도 같은 [출력]이 있다(월~금, 시험으로 쉬는 날은 이유). 문서 = `src/lib/dutyRosterPrint.ts`, 회귀 = `scripts/duty-roster-print-test/run.mts`.
