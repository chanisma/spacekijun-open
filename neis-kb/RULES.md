# 나이스 교무업무 — 화면을 넘나드는 규칙

화면 안내(`guides/`)는 화면 하나씩이라 «A 를 먼저 안 하면 B 가 비어 보인다» 같은 **화면 사이의 규칙**이 흩어진다.
이 문서는 그것만 모았다. 근거는 2026 상반기 나이스 교무업무 사용자 설명서(`manual/`, 절 ID 를 괄호에)이고,
2026-10-11 설명서로 안내 209개를 쓰면서 확인한 것이다. **사람이 쓴 문서** — `manual.py` 가 덮어쓰지 않는다.

이 부류는 나이스가 **오류를 내지 않는다**. 화면이 비어 있거나, 버튼이 안 보이거나, 숫자가 조용히 어긋날 뿐이다.
AI 가 나이스 업무를 계획할 때는 화면 안내의 `before` 와 함께 이 문서를 먼저 읽는다.

## 1. 권한·결재

1. **편성 ≠ 권한.** 담임(「학급담임편성관리」)·교과담당(과목개설)·동아리(부서만들기)를 편성하거나 업무분장에서 자료권한을
   등록해도 «미상신»일 뿐이다. 「교무자료권한승인관리」의 학년반·교과목·동아리활동 탭에서 [승인요청] → 학교장 결재가
   끝나야 권한이 생긴다. 조회할 때 «담임편성» / «권한관리» 중 맞는 쪽을 골라야 목록이 보인다. (1-02, 2-03)
2. **결재 뒤 되돌리기는 상신함부터.** 「상신함」[기결문서취소] → 그 결재 완료 → 원래 화면의 [마감취소]·[학적반영취소]·[제거].
   월출결 마감·학교일지·졸업/전입 학적반영·추정분할점수·수상대장이 모두 이 순서다. 기안자가 전보·퇴직으로 못 하면
   관리자가 「결재현황판관리」에서 문서를 삭제(사유 기록 → 미상신 상태). (1-06)
3. **결재선은 우선순위를 정해야 들어간다.** 결재선을 등록해도 「결재문서관리」의 «결재선우선순위»를 지정하지 않으면 자동
   적용되지 않는다. 기관결재선 > 개인결재선. (1-06)
4. **새로 온 교원은 임시교원으로 먼저.** 신규·타시도 전입 교원·시간강사는 「발령전 임시교원 등록」 → 6개월 안에
   「임시교원권한이양」으로 정식 아이디에 이양 → 자료권한은 다시 승인요청. 시간강사도 여기 등록해야 시간표에 넣을 수 있다. (1-03)
5. **세특 화면 셋은 2차 인증 사용자 등록이 먼저.** 과목별·개인별·편입/복학생 세특은 「2차인증사용자관리」에서 관리자가
   승인(«등록완료»)해야 들어간다. (1-08)

## 2. 학사일정·시간표·출결

6. **공휴일정보생성이 먼저.** 「학사일정관리」[공휴일정보생성]을 안 하면 「출결관리」 반별일출결마감에서 토요휴업일에도 마감 칸이
   생긴다. (2-06)
7. **마감 뒤 학사일정을 고치면 학교일지를 다시 만든다.** 출결 마감이 끝난 날의 학사일정을 바꾸면 「학교일지관리」에서 그날을
   [제거] → [생성]해야 수업일수에 반영된다. (2-06, 2-09)
8. **모든 숫자의 기준은 「전체시간표관리」.** 동아리·자율활동이 시간표에 없으면 이수시간 기준일이 안 잡히고 출석부도 안 뜬다.
   누가기록 뒤에 시간표를 바꾸면 학생부 이수시간과 누가기록 합계가 어긋나고, 출결 마감 뒤 추가한 교시는 결과(/)로 처리되지 않는다. (2-07)
9. **창체 이수시간은 누가기록의 합이 아니다.** 시간표 시수 + 학사일정 행사코드의 «학생부특별활동» 값 + 출결로 계산된다.
   누가기록 뒤 결석 처리돼도 기록은 자동 삭제되지 않고, 반 변경 시 [이수시간반영]은 변경 **전** 시간만 센다 → 학생부
   자료검증이 «확인필요»를 낸다. (2-06, 5-01, 3-01)
10. **결보강 사유를 비우면 결보강이 아니다.** 사유 없이 처리하면 교사만 바뀌고 「결보강일지조회」에 안 나온다. 처리 뒤 교시를
    지우고 [수업추가]로 다시 넣어도 보강으로 인식되지 않는다. (2-07)
11. **기초시간표를 과거 날짜로 반영하면 이력이 지워진다.** 「기초시간표검증및반영」에서 오늘 이전 날짜로 반영하면 그 기간의
    결보강·수업교체 이력이 모두 사라진다. 월출결마감이 끝난 기간은 반영되지 않는다. (2-07)
12. **출결 마감은 사슬이다.** 교시 마감 → 반별 일·월 마감 → 학기별 과목 마감(과목교시마감수 = 반별일출결마감수 = 시간표총수업수일
    때만) → 과목 전체 마감. 고칠 때는 거꾸로 푼다. 월마감한 달만 학생부 «출결상황»에 들어가고(학생부반영 후), 월마감 취소는
    그 달 통계를 지운다. (3-07, 3-08)
13. **수업일수는 두 가지다.** 「출결현황및통계」의 값은 전체시간표 기준이라 학생부 값과 다를 수 있다. 확정은 학년말 월마감 →
    학생부반영 «출결상황» 뒤. (3-08)

## 3. 성적

14. **만점이 셋에서 맞아야 한다.** 문항정보표 과목점수 합계 = 「반영비율/만점관리」 만점이어야 마감되고, 반영비율 합계는 100%. (6-01, 6-02)
15. **채점 뒤 문항정보표를 고치면 채점·성적이 지워진다**(서답형 점수 포함) → 재채점, 재채점도 「성적처리이력조회」에 수정 이력으로
    남는다. 학생답안 파일을 다시 올리면 학생답관리에 넣은 서답형 점수가 지워진다. (6-02)
16. **시행일자 종료일까지 문항정보표는 처음 등록한 교사만.** 바꾸려면 「문항정보표사용자관리」. (6-02)
17. **성취기준은 연결하면 잠긴다.** 문항·수행평가 영역에 연결한 성취기준은 고치거나 지울 수 없다. (6-01)
18. **마감이 다음 단계를 연다.** 정기시험·수행평가 강의실별 마감 + 마감정보 저장 → 「성적산출선행작업관리」에서 고사/영역 선택 가능 →
    「성적산출관리」 산출 → 「성적산출마감관리」 마감 → 교과학습발달상황·최소성취수준 대상자 가져오기·공동교육과정 성적 전송.
    거꾸로, **정기시험·수행평가 마감을 취소하면 이미 산출한 학기말 성적이 지워진다.** (6-05)
19. **«학기말» 성적산출기준명은 학기당 하나, 없으면 여러 기능이 조용히 막힌다** — 위탁학생 성적 입력, 교양교과 이수처리,
    공동교육과정 성적 수신, 교과우수상 등록([성적우수자수상등록]이 «-없음-»). 기준명을 지우면 담임이 쓴 가정통신문도 지워진다. (6-05)
20. **결시생이 없어도 [인정점산출].** 안 하면 과목별 성적산출이 안 된다. 기준고사는 1차↔2차로 엇갈리게 정해야 «질병결» 등에
    인정점이 부여된다. (6-05)
21. **최소성취수준 보장지도는 맨 끝.** 교시별 출결마감 → 학기별과목출결마감 → 성적산출마감이 다 끝나야 [대상자가져오기]가 켜진다.
    한 과목이라도 가져오면 학기말 성적산출마감을 취소할 수 없고, 출결을 고치면 보장지도를 가져오기부터 다시 한다. (6-05, 3-07)
22. **전입생 전적교 성적은 「전입자료관리」에.** 정기시험·수행평가성적관리에 넣으면 응시자 수·평균에 섞인다. 전입자료관리 칸이
    꺼져 있으면 이미 성적 화면에 넣은 것 — 거기서 먼저 지운다. (3-02)
23. **이전년도 성적 반영은 재산출이 먼저.** 「기준년도/학기관리」를 그 학년도로 바꿔 재산출 → 현재 학년도로 되돌려야
    「이전년도성적자료반영」에 과목이 보인다. (7-02)

## 4. 학생부·정정

24. **정정대장은 결재 완결 순간 자동 반영, 그 뒤 나이스에서 못 고친다.** 4단 결재(담임→부장→교감→교장, 대결·전결 불가),
    같은 학생은 앞 건 완결 뒤에 새 건. 재학생·졸업생·보존 졸업생 세 화면 공통. (7-02, 3-16)
25. **졸업대장만 고치면 학생부와 어긋난다.** 학생부가 있는 졸업생은 「졸업생학생부정정대장작성」으로 고쳐야 둘이 함께 바뀐다. (3-16)
26. **독서활동은 두 곳.** 과목 관련은 교과교사가 「과목별독서활동」, 공통은 담임이 「독서활동상황기록」. 과목별 화면은 빈칸 저장이
    안 돼 지우려면 담임 화면에서 [삭제]. [일괄입력]의 [덮어쓰기]는 고른 학생의 기존 기록을 지운다. (5-08)
27. **봉사활동은 출결과 연동되지 않는다.** 반별 일괄등록 때 결석생을 담임이 직접 뺀다. 2024 대입부터 상급학교에는 «학교» 봉사만. (5-03)

## 5. 학적 — 전출입·진급·졸업·입학

28. **전입·재입학 뒤 수강과목편성이 없으면 출결·성적이 안 된다.** 2026 1·2학년(2022 개정)은 「전입관리」의 수강과목편성 창에서만
    (전출교 과목과 매칭). 3학년(2015 개정)은 「학생별수강과목편성」에서도. 반 변경은 학기초 = 지우고 새로, 학기중 = 두고 추가. (3-02, 2-05)
29. **학적 변동일까지 학생부를 생성한다.** 전출·휴학/자퇴·통폐합 모두 변동일 기준으로 학교생활기록부를 생성해야 학적사항·출결이
    그날 끊긴다(변동일 자체는 수업일). 순서: 일반 전출 = 생성→전송→상신→학적반영, 통폐합 = 생성→상신→학적반영→전송. (3-04, 3-05)
30. **진급 순서.** 유급자·조기진급자를 진급대상자 생성보다 **먼저** 등록, 반편성 배정도 생성보다 먼저. 학적반영은 학생부·건강기록부
    마감 뒤 졸업생 → 3·2·1학년 순. (3-06)
31. **졸업 순서.** 조기졸업자·수료자 등록 → 「졸업/수료대상자 관리」[생성](이후 앞 화면 잠김) → 「졸업/수료대장 번호 부여」 →
    결재 → 「졸업/수료생 학적반영」. 대장번호의 졸업일자는 학사일정의 **졸업식** 날짜 — 없으면 2월 28일로 조용히 들어간다.
    [작업실행]은 학생부에 졸업 사항을 바로 쓰므로 졸업 기록 전 학생부가 필요하면 그 전에 출력. (3-15)
32. **입학 «본교확인 = 비대상»은 되돌릴 수 없다.** 학적 일괄생성 때 그 학생의 보건·기본정보가 지워지고, 나중에 «대상»으로 바꿔도
    출신 중학교에 다시 전송요청해야 한다. (3-19, 9-01)
33. **타교수강생은 왕복.** 거점교 등록·[확인요청] → 참여교 결재·[요청확인] → 거점교 결재·[학적반영]. 반 정보(「타교 수강생 반 정보
    관리」)를 먼저 만들어야 학년·반을 고를 수 있다. 자동으로 들어온 성적·세특·수상은 학생부반영 전에는 학생부가 아니다.
    위탁생 출결은 학기말이 아니라 **달마다** 마감·결재·전송. (3-11~3-13)

## 6. 개별화교육·보건

34. **개별화교육은 인적사항이 먼저.** 「인적사항관리」에서 대상자 등록을 해야 계획관리 목록에 학생이 나온다. 결재 뒤 수정은 기결취소
    없이 되지만 «마감이후 수정 사유»가 필요하고 저장 즉시 반영된다(승인요청은 「마감이후수정이력조회」에서 따로). (4-01, 4-03)
35. **감염병 보고서가 생성되면 환자등록에서 못 고친다.** 제출 전 = 「감염병보고제출」에서 보고서 삭제 후 수정, 제출 후 =
    「감염병환자조회및수정보고제출」로 수정보고. (8-02)
36. **건강기록부 반별 [마감]은 조건이 맞아야 보인다** — 반 전원의 검진·신체능력·신체발달 등록(또는 «자료검증대상제외»). 반별 마감이
    안 되면 「건강기록부마감」 승인요청도 막힌다. 건강기록부 정정은 결재 뒤 [완결자료반영]까지 해야 반영된다(학생부 정정과 다름). (8-01)

## 7. 설명서와 지금 화면이 다른 곳 (전북 나이스, 2026-10 수집본 기준)

- **이름**: 설명서 «지필평가…» = 메뉴 «정기시험…» · «성취평가기준관리» = «성취기준관리» · «학교업무분장권한이양» = «임시교원권한이양» ·
  [지필/수행점수누락자보기] = [정기시험/수행평가 점수누락자 보기] · [지필/수행학업성취율현황] = [학업성취율 현황] · 결보강일지 [생성] = [일괄생성] ·
  «동아리활동기록(담임용)» = 「동아리활동관리(담임용)」 · 동아리 담임용 {위탁가져오기} = [위탁/공동 가져오기].
- **조회 조건**: 설명서의 «계열/학년/학과» → 화면은 «학년»(또는 학년·반) — 정정 일괄·NCS·자격종별 화면.
- **[승인요청]이 수집본에 없는 화면이 많다**(마감관리·조기진급·추가입학·입학생교육과정·위탁 확인요청 등) — 대개 조회·행 선택 뒤에
  나타나는 버튼이라 수집 시점에 안 보였던 것으로 본다. 안내는 글로만 설명했다.

## 8. 다시 수집해 볼 화면 (수집기 쪽 의심)

안내를 쓰다가 «수집본이 화면과 다르다»고 판단한 곳. 재수집 또는 `collect.py` 개선 대상이다.

- **탭을 눌렀는데 첫 탭과 같은 요소가 잡힘**: 「이동수업(N+1)학생관리」 탭 2~5 · 「동아리활동관리」 동아리활동 출결관리 탭 ·
  「학생주소연계」 연계결과 확인 및 반영 탭 · 「전입자료관리」 독서활동 탭(세특과 동일) · 「인적사항관리」 진단평가 탭 · 통폐합 전출 상신 탭.
- **버튼이 탭 목록(items)에 섞여 잡힘**: 「타교수강생관리(위탁)」 [확인요청]·[승인요청]·[학적반영] · 「과목별출결관리」 [전체마감]·[출결마감] ·
  「출결관리」·「전입관리」 «출결마감»·«자료요청»·«학적반영» — 단계 버튼(`via: buttons`) 판정이 본문 버튼까지 삼키는 것으로 보인다.
- **라디오 라벨이 엉뚱함**: 「강의실별수업일수조회」 `radio:학기`(실제 강의실별/반별/개설강좌별) · `radio:학년도`(기간별/월별/날짜별) ·
  「학기말성적조회」 `radio:강의실`(실제 환산점기준/받은점수기준).
- **일부 탭만 수집**: 「학기말성적조회」 15탭 중 3 · 「학교생활기록부」 6탭 중 2 · 「진급대상자 반편성관리」 진급자학적반영·진급누락자처리·
  개별반편성 · 「분할점수관리」 수행평가·학기말 쪽.
