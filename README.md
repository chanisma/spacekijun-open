# SPACEKIJUN — 학교 교직원 업무 시스템

한 고등학교에서 교사가 직접 만들어 운영해 온 **교직원 업무 시스템**의 공개판입니다.
이 저장소로 우리 학교만의 SPACEKIJUN 을 세울 수 있습니다.

> 이 공개판에는 **실제 학교의 데이터가 들어 있지 않습니다.** 사람 이름·학번·이메일·전화번호는
> 가상 값으로 바뀌었고, 데이터베이스는 구조(표·함수·권한 정책)만 담았습니다(행 0개).
> 학교 이름·코드는 자리표시값(`샘플고등학교`, `9999999` …)이며 `scripts/setup-school.mjs` 로 한 번에 바꿉니다.

## 무엇이 들어 있나

| 영역 | 내용 |
|---|---|
| 업무 | 업무 › 할 일 › 작업 3층 구조, 업무노트, 업무 흐름 캔버스, 제출·입력 받기, 연간 이어가기 |
| 학교 운영 | 시간표·수업 교체, 일정·학사력(NEIS), 급식지도·자습 감독 배정, 결재·전자서명, 서류함, 구매 신청·예산, 동아리, 공지 |
| 학생 | 학생 기록(evalog)·모의고사 분석·교과 분석·수시 지원 관리·탐구 설계·면접 준비 |
| 게임형 학습 | 다마고찌 · 별빛 아카데미 · 별까지 쌓기(집중 타이머) · 이세계 사회인 기록 · 코인 경제 |
| 에이전트 | MCP 서버(엣지 함수 `mcp`) — 교사 본인 권한으로 Claude 등 에이전트가 업무 도구를 부른다 |
| 휴대폰 | `/m` 모바일 앱 |

## 기술 스택

React 18 + TypeScript + Vite · Tailwind + shadcn/ui · TanStack Query · Supabase(PostgreSQL + RLS + Edge Functions + Storage) · Google OAuth

## 시작하기

설치 절차는 **[SETUP.md](SETUP.md)** 를 따르세요. 요약:

```bash
npm install
cp .env.example .env.local                 # Supabase 주소·키
cp school.config.example.json school.config.json   # 학교 이름·코드
node scripts/setup-school.mjs --write
# Supabase 에 supabase/schema/*.sql 적용 → 엣지 함수 배포
npm run dev
```

## 문서

- `CLAUDE.md` — 전체 구조와 규칙(사고가 났던 자리 포함). Claude Code 로 개발한다면 자동으로 읽힙니다.
- `docs/features/*.md` — 기능별 설계, `docs/database/*.md` — 스키마
- 문서 속 사람 이름은 가상 이름입니다. 일부 문서는 원래 학교의 운영 맥락(학년 수·반 수 등)을 전제로 쓰였습니다.

## 주의

- **생기부 본문과 성적은 DB 에 올리지 않고 교사 PC 의 로컬 파일로 씁니다.** 자세한 내용은 `docs/student-records-local.md` 에 있습니다.

- 학생 개인정보를 다루는 시스템입니다. 운영 전에 학교의 개인정보 처리 절차(동의·보관 기간·접근 권한)를 확인하세요.
- `.env*`, `school.config.json`, `supabase/schema/30_private_config.sql` 처럼 비밀값이 든 파일은 커밋하지 마세요.

## 라이선스

[SPACEKIJUN 교육용 비상업 라이선스 1.0](LICENSE)

- **학교 안 활용은 자유롭습니다.** 학교(국공립·사립)와 교직원·학생이 수업·학교 업무·학생 활동에 쓰고, 자기 학교에 맞게 고치고, 학교 서버나 교육청 클라우드에 설치해 운영할 수 있습니다. 교육청·교사 연구회·비영리 교육 단체가 고친 것을 다른 학교와 나누는 것도 자유입니다.
- **상용 서비스 제작에는 쓸 수 없습니다.** 유료 판매·구독 상품, 영리 목적의 웹 서비스·앱(수익 방식 불문), 영리 기업 제품이나 사교육 상품에 넣는 것은 저작권자의 서면 허락이 필요합니다.
- 외부에서 가져온 코드·자료는 각자의 라이선스를 따릅니다.
